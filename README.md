## 📌 What Is This?

**awesome-research-hub** is the most comprehensive, community-driven knowledge repository for **software engineers, AI/ML researchers, systems architects, and technical leaders** who want to go from good to exceptional.

Inspired by the DNA of the top 5 most-starred GitHub repositories ever:

| # | Repository | Stars | Lesson Borrowed |
|---|-----------|-------|----------------|
| 1 | `build-your-own-x` | 517k⭐ | Learn by building from scratch |
| 2 | `awesome` | 477k⭐ | Curated lists with signal-to-noise ratio |
| 3 | `freeCodeCamp` | 450k⭐ | Structured, free, open learning |
| 4 | `public-apis` | 443k⭐ | Instantly actionable references |
| 5 | `free-programming-books` | 390k⭐ | Democratize access to knowledge |

This repo is **all five, unified**.

## 🛠️ Build Your Own X

> The fastest way to understand something deeply is to build it yourself.

```
Build your own:
├── 🔧 Programming Language    → Crafting Interpreters (free book)
├── 🌐 Web Server              → Build HTTP/1.1 from TCP sockets
├── 🗄️  Database               → CMU 15-445 project series
├── 🔁 Version Control (Git)   → Write Git in Python (~500 lines)
├── 🧠 Neural Network          → Karpathy's micrograd (< 100 lines)
├── 🐳 Container Runtime       → Linux namespaces + cgroups from scratch
├── 🔐 Blockchain              → Naivecoin tutorial
├── 📡 DNS Resolver            → Implement RFC 1035 yourself
├── ⚙️  Operating System       → xv6-riscv walkthrough
└── 🤖 LLM                     → nanoGPT + nanochat
```

Each item above is linked in the full wiki. Every project includes: starter repo, difficulty rating, estimated time, and a "what you'll learn" summary.

## 🏆 The 100-Day Learning Challenge

> Inspired by `#100DaysOfCode` — but engineered for depth, not just consistency.

```
Week 1–2:   Algorithms & Data Structures (LeetCode Patterns)
Week 3–4:   Build something from scratch (pick from Build Your Own X)
Week 5–6:   System Design fundamentals (system-design-primer)
Week 7–8:   Read 4 papers (Papers We Love selection)
Week 9–10:  Train a small model end-to-end (nanoGPT)
Week 11–12: Contribute to an open source project in your domain
Week 13–14: Write a blog post or give a talk about what you learned
```

Track your progress: open an issue with the title `[100-Day Challenge] Your Name` and update it weekly. The community will keep you accountable.

## 🤝 How to Contribute

This repository is **community-first**. Every link, every explanation, every correction makes it better for everyone.

**Adding a resource:**

```bash
# 1. Fork and clone
git clone https://github.com/Ciprian-LocalPulse/awesome-research-hub

# 2. Create a branch
git checkout -b add/your-resource-name

# 3. Add your resource following the format below
# 4. Run the link checker
npm run check-links

# 5. Submit a Pull Request
```

**Resource format:**
```markdown
- 📘 [Title](URL) — One sentence: what it is and why it's worth your time
```

**Quality bar:** A resource earns its place if it answers "yes" to at least two of:
- [ ] Is this the best explanation of this concept you've found?
- [ ] Would a senior engineer at a top company point a junior to this?
- [ ] Does this contain something you can't easily find elsewhere?
- [ ] Has this withstood the test of time (or is genuinely cutting-edge)?

See [CONTRIBUTING.md](./CONTRIBUTING.md) for full guidelines.
