# 🏆 The 100-Day Research & Engineering Challenge

> A structured, community-tracked curriculum for going from good to exceptional.  
> Inspired by `#100DaysOfCode` — engineered for depth, not just consistency.

---

## How It Works

1. **Start an issue** titled `[100-Day Challenge] Your Name — Start Date`
2. **Follow the weekly curriculum** below (or adapt it — the structure is a guide, not a cage)
3. **Update your issue** every Friday with: what you did, what surprised you, what's next
4. **The community** will follow along, ask questions, and keep you accountable

No gatekeeping. No prerequisites. Start from wherever you are.

---

## The 14-Week Curriculum

### 📅 Weeks 1–2: Foundations
**Theme:** Algorithms & Problem Solving

| Day | Task |
|-----|------|
| 1–3 | Complete [LeetCode Patterns](https://github.com/seanprashad/leetcode-patterns) — arrays & hashing |
| 4–7 | Implement 5 sorting algorithms from scratch (no looking) |
| 8–10 | Trees, graphs — DFS, BFS, Dijkstra |
| 11–14 | Dynamic programming fundamentals — 10 classic problems |

**Checkpoint:** Solve a LeetCode Medium you couldn't solve on day 1.

---

### 📅 Weeks 3–4: Build Something From Scratch
**Theme:** Deep Understanding Through Construction

Pick **one** from the [Build Your Own X](../README.md#️-build-your-own-x) list:

| Level | Project | Time |
|-------|---------|------|
| Beginner | Git clone in Python | ~8h |
| Intermediate | HTTP web server in Go | ~12h |
| Advanced | Neural network from scratch (no PyTorch) | ~20h |
| Expert | Build a simple interpreted language | ~40h |

**Checkpoint:** Your build runs. Write 300 words on what surprised you.

---

### 📅 Weeks 5–6: System Design
**Theme:** Think at Scale

| Day | Task |
|-----|------|
| 1–3 | Read system-design-primer intro + CAP theorem |
| 4–5 | Design a URL shortener (whiteboard style) |
| 6–8 | Design a rate limiter |
| 9–11 | Read Designing Data-Intensive Applications Chapter 1–3 |
| 12–14 | Design a notification system (push + email + SMS) |

**Checkpoint:** Write up one of your designs as a structured document.

---

### 📅 Weeks 7–8: Read 4 Research Papers
**Theme:** Stand on the shoulders of giants

Suggested sequence for first-timers:

| Paper | Why |
|-------|-----|
| [MapReduce (2004)](https://research.google/pubs/pub62/) | Foundation of big data processing |
| [Raft Consensus (2014)](https://raft.github.io/raft.pdf) | Understandable distributed consensus |
| [Attention Is All You Need (2017)](https://arxiv.org/abs/1706.03762) | The Transformer paper |
| One paper from your domain | Apply the skill to what you care about |

**How to read a paper:**
1. Abstract + conclusion first (5 min)
2. Introduction + figures (20 min)
3. Full read, skip math proofs (40 min)
4. Related work + references to follow up (20 min)

**Checkpoint:** Post a 3-sentence summary of each paper in your issue.

---

### 📅 Weeks 9–10: Train a Model End-to-End
**Theme:** AI from data to deployment

| Day | Task |
|-----|------|
| 1–2 | Setup environment, clone [nanoGPT](https://github.com/karpathy/nanoGPT) |
| 3–4 | Understand the data loading and tokenization pipeline |
| 5–7 | Train on a small dataset of your choice |
| 8–10 | Evaluate outputs, tweak hyperparameters |
| 11–14 | Write a blog post or README about what you learned |

**Checkpoint:** You have a model checkpoint and you understand every line of the training loop.

---

### 📅 Weeks 11–12: Open Source Contribution
**Theme:** Give back, build reputation

Steps:
1. Find a repo you've used from this list
2. Read CONTRIBUTING.md
3. Fix a good-first-issue or improve documentation
4. Submit a PR
5. Iterate on reviewer feedback

**Checkpoint:** At least one PR merged or substantively reviewed.

---

### 📅 Weeks 13–14: Teach What You Learned
**Theme:** The best test of understanding is explanation

Options (pick one):
- Write a 1,000-word blog post on your biggest insight
- Give a 15-minute lightning talk at a meetup or to colleagues
- Create a visual explainer (diagram + walkthrough)
- Record a 10-minute video walkthrough of your build

**Checkpoint:** The thing is published and you've shared the link.
